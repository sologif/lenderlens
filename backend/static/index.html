Threat Analysis

Predatory Syndicate Vectors

VEC-01 · REGULATORY SPOOFING
Licensed NBFC Impersonation
Scam operators cite registered entity names like "ABC Finance Ltd." but host forms on unlisted rogue domains to evade basic name searches.
VEC-02 · ADVANCE FEE FRAUD
Upfront Security Deposits
Victims are told their loan is approved but must pay an upfront ₹1,500 "activation/insurance fee" to disposable mule UPI IDs before release.
VEC-03 · PERMISSION HARVESTING
Blackmail Device Telemetry
Sideloaded apps request Contacts, SMS, Call Logs, and Photos, which recovery syndicates harvest for extortion and reference harassment.
VEC-04 · ZERO EARLY WARNING
Post-Victimization Discovery
Borrowers only realize they have been defrauded after money is sent, with no real-time browser warning to block payment routing.
