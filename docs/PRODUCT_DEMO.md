# LenderLens Product Demo

## Judge / reviewer flow

1. Open `http://localhost:8000/`.
2. Use **Try the live demo** or scroll to **Live Product Demo**.
3. Switch between **FastCash**, **QuickLoan**, and **ABC Finance** to demonstrate the three risk outcomes.
4. Click **Scan page** to replay the extension-style analysis.
5. Click **Open analyst case** to move into the investigation console.
6. From the website, use **Get the extension** to open the extension package/source and install it as an unpacked Chrome Manifest V3 extension for the prototype.

## Product story

**Borrower → Browser scan → Evidence → Risk decision → Analyst case**

The website intentionally mirrors the browser extension experience so a demo audience can understand the product without installing Chrome first.

## Demo data notice

The lender names, registration records, fraud relationships, temporal activity and risk outcomes shown in the prototype are simulated/reference data. Production use requires authorized regulatory data sources, validated datasets, security controls and model validation.
