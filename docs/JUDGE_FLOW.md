# LenderLens Judge Flow

**10-second view:** LenderLens protects the borrower in the browser and gives analysts a deeper investigation path when risk is unclear.

**Demo:** Website → Live Product Demo → FastCash / QuickLoan / ABC Finance → Scan page → Open analyst case → Dashboard.

**Core message:** `Borrower → Browser scan → Evidence → Risk decision → Analyst review`

**Three outcomes:**
- ABC Finance → 18/100 → ALLOW
- QuickLoan → 56/100 → REVIEW
- FastCash → 91/100 → BLOCK

This flow intentionally makes the extension understandable from the website before asking a judge to install anything.
