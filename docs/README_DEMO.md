# LenderLens Demo Entry Point

Open the running app at `/`.

- Marketing site: `/`
- Interactive extension simulation: `/#demo`
- Analyst dashboard: `/dashboard/index.html`
- Demo lenders: `/demo/legitimate/index.html`, `/demo/uncertain/index.html`, `/demo/fraudulent/index.html`

The public site now acts as the first demo surface, so evaluators can see the borrower journey without first installing the browser extension.
